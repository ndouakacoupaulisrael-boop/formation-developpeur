# Portfolio — structure et critères du cours

- Site principal en une page avec menu à ancres / défilement vers les sections.
- Sections : présentation, CV / formation / compétences, 3 à 6 projets, contact.
- HTML sémantique ; CSS3 avec modèle de boîte, Flexbox et grille ; mise en page responsive.
- Le portfolio comprend une version CV imprimable (`cv.html`).
- Les cartes de projets renvoient vers les dépôts GitHub connus.
- Le CSS comprend des adaptations mobile, tablette et écran large, ainsi qu'un style d'impression.

## Points à compléter par l'étudiant

1. Ajouter une adresse e-mail, un numéro de téléphone et le lien LinkedIn réel.
2. Vérifier chaque description de projet et retirer les éléments qui ne sont pas présentables publiquement.
3. Ajouter des captures d'écran réelles des applications si disponibles.
4. Faire une démonstration sur ordinateur puis sur téléphone pour montrer le responsive.
